  <action>
  1. toWorld(cx, cy): r = svg.getBoundingClientRect(); return {x:(cx-r.left-view.x)/view.k, y:(cy-r.top-view.y)/view.k}. toScreen(wx, wy): inverse — {x: wx*view.k + view.x + r.left, y: wy*view.k + view.y + r.top}.
  2. applyView(): set svg viewBox to clientWidth x clientHeight; worldG transform = translate(view.x, view.y) scale(view.k); grid pattern transform synced to translate(view.x % (GRID*view.k), view.y % (GRID*view.k)) so dots stay anchored; #zoomPct text = Math.round(view.k*100)+'%'. Listen resize → applyView.
  3. zoomBy(cx, cy, factor): r = svg.getBoundingClientRect; px=cx-r.left, py=cy-r.top; k2 = clamp(view.k*factor, 0.2, 4); keep world point under cursor stationary: view.x = px - (px-view.x)*k2/view.k; view.y = py - (py-view.y)*k2/view.k; view.k = k2; applyView(). Wheel handler: zoomBy(ev.clientX, ev.clientY, ev.deltaY<0?1.12:0.89), preventDefault, passive:false.
  4. zoomFit(): if no nodes and no zones → view={x:0,y:0,k:1}; applyView; return. Else compute bbox of all nodes (n.x..n.x+nodeW) and zones (z.x..z.x+z.w), pad 40px; k = min(clientW/(maxX-minX), clientH/(maxY-minY), 1.5); center via view.x/y; tweenView to the target (or set directly if no tween yet — see below).
  5. tweenView(tx, ty, tk, ms=300): rAF-eased lerp from current view to target over ms. Each frame: t = elapsed/ms (clamped 0..1); ease = t<0.5 ? 2*t*t : 1-((1-t)^2); view.x = lerp(view.x, tx, ease); view.y = lerp(view.y, ty, ease); view.k = lerp(view.k, tk, ease); applyView(); if t<1 requestAnimationFrame next frame. Guard against overlapping tweens (cancel any active rAF id before starting new). zoomFit calls tweenView; zoomPct click (100% reset) calls tweenView(0,0,1).
  6. openEditor(target, type, id): position #labelEditor at the element's screen position (toScreen of center), set value to current label, focus + select. commitEditor(): obj.label = editor.value || obj.label; hide editor; commit(); renderAll(). hideEditor(): editor.style.display='none'; editor.onblur=null. dblclick handler: hit g.nodeg → openEditor(node, 'node', id); g.zoneg → openEditor(zone,'zone',id); g.edge (if edges selectable) → openEditor(edge,'edge',id) editing edge.label. Enter → commitEditor; Escape → hideEditor (no commit). Blur → commitEditor.
  7. updateProps(): if no sel → hide panel. Node: #propsTitle='Node'; #pLabel.value = n.label; build swatches (SWATCHES) with .on matching n.color, click → n.color=c; commit(); renderAll(); updateProps(); render effects chips from EFFECTS catalog (toggle per-node effects like halo/animated) — clicking toggles and commits. Edge: #propsTitle='Link'; label (edge.label); dash style select (solid/dashed/dotted/sneakernet/animated) → e.dash; mode toggle (curve/ortho) → e.mode; anim checkbox → e.anim. #pDelete button → deleteSelection. #pLabel input → updates label live + renderAll (commit on blur).
  8. EFFECTS catalog: small map of effect name → renderer/applier (e.g. halo: draws a glow rect behind node; animated: sets e.anim). At minimum include 'halo' and 'animated' as toggleable chips. <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| keyboard/pointer input → tool dispatch | key events while an input is focused must not trigger tools |
| props panel input → state | user-typed label text flows into state and SVG |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | props label input / labelEditor → SVG text | medium | mitigate | textContent/esc() only (same discipline as T-01-01); no innerHTML with user strings. |
| T-03-02 | DoS | Ctrl+S held down (repeated exportJSON) | low | mitigate | exportJSON is cheap (Blob of a few hundred KB); debounce/throttle Ctrl+S to one export per keypress repeat cycle — native keydown repeat already rates it; accept residual. |
| T-03-03 | Elevation | none — no privileged APIs | low | accept | Client-only, no backend, no eval/Function of user input. |
</threat_model>
