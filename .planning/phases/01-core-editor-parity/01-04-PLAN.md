<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| imported JSON file → state | untrusted user-supplied JSON crosses into the in-memory model (highest-risk boundary in Phase 1) |
| localStorage → state on boot | previously-saved doc is parsed and applied at startup |
| serialize() → localStorage | app state written to a quota-limited store |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering | applyLoadedDoc / importJSON prototype-pollution | high | mitigate | Build fresh arrays with explicit field picks per element (step 4 of Task 1); read only known top-level keys (nodes/edges/zones/meta); never for-in assign raw parsed objects onto existing objects or Object.prototype; drop unknown top-level keys. Acceptance criterion: round-trip + unknown-key-drop verified; a JSON containing "__proto__"/"constructor"/"toString" keys at top level does not alter Object.prototype (test: Object.prototype.polluted is undefined after load). |
| T-04-02 | DoS | giant-file / huge-element-count import | high | mitigate | Reject file.size > 20MB and parsed nodes+edges+zones > 20000 with inline error, state unchanged (Task 1 step 7). |
| T-04-03 | DoS | localStorage quota exhaustion (autosave) | medium | mitigate | saveSoon wraps setItem in try/catch; on QuotaExceededError log console.warn once and continue (app stays usable; autosave disabled silently for the session). Acceptance: filling localStorage to quota does not throw or freeze the app. |
| T-04-04 | Information disclosure | localStorage diagram contents | low | accept | Local single-user machine; diagram is user's own data; no cross-origin exposure (file:// origin). ASVS L1 accepts. |
| T-04-05 | Tampering | imported node/edge/zone label text → SVG | medium | mitigate | esc()/textContent discipline on render (T-01-01); imported labels pass through the same render path — no innerHTML with imported strings. |
</threat_model>
