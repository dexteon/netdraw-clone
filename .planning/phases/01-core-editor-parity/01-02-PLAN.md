## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input → state via undo snapshots | parsed JSON restores state; a malformed snapshot could corrupt model |
| edge labels → SVG | edge label pill text rendered into SVG text elements |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | undo()/redo() JSON.parse of snapshots | medium | mitigate | Snapshots are self-generated via serialize() (trusted origin), never user-supplied; wrap restore in try/catch that keeps prior state on parse failure and logs to console.error. Acceptance: corrupting an entry to invalid JSON does not crash the app (state unchanged, no uncaught exception). |
| T-02-02 | Tampering | edge label pill text | medium | mitigate | Edge label set via textContent / esc() only — same discipline as node/zone labels (see T-01-01). |
| T-02-03 | DoS | undoStack growth | low | mitigate | Cap 120 with shift() — enforced in acceptance criteria; memory bounded. |
</threat_model>
