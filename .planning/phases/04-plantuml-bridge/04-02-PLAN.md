<objective>
Build the PlantUML **export** half of the bridge: a serializer that walks editor state back to PlantUML component syntax (zones→packages, nodes→component declarations, edges→labeled arrows) and an exportPuml() driver that downloads a .puml file (M-22). Verify the AC-3 round-trip contract — .puml → diagram → .puml preserves nodes, edges, zone containment, and labels at the model level.

Purpose: Export closes the bidirectional bridge. It must be the deterministic inverse of pumlParse on the supported subset so the round-trip holds.
Output: index.html extended with pumlSerialize(state) and exportPuml(), plus an "Export PlantUML" menu entry.
</objective>

  <action>
  Append pumlSerialize to the PlantUML bridge module section (same script block as pumlParse). It is a pure function returning a string — no DOM side effects.

  1. Header: emit `@startuml` as the first line and `@enduml` as the last (standard PlantUML envelope; round-trip-friendly).

  2. Zones → packages: iterate state.zones in id/insertion order. For each zone, emit `package "<label>" as <sanitizedId> {`. Sanitize the zone's id to an alnum alias for use as the PlantUML package alias (replace non-alnum with "_"; never use a raw id that could collide with a PlantUML keyword — prefix with "z_" if it begins with a digit). Inside the package block, emit the nodes whose inZone(n.id) === zone.id as `component "<label>" as <sanitizedNodeId> <<stereotype>>` where stereotype is derived from the inverse of PUML_STEREOTYPE_MAP when node.type maps back to a known keyword, else omitted. Close with `}`. Nested zones (if Phase 1 supports zone nesting) emit as nested package blocks; otherwise document that v1 flattens one level of zone nesting (nodes in nested zones attach to the outermost package).

  3. Unzoned nodes: after all package blocks, emit nodes with no zone containment as `component "<label>" as <sanitizedNodeId> <<stereotype?>>` at the top level.

  4. Edges → arrows: iterate state.edges in id/insertion order. Emit `<fromAlias> --> <toAlias> : <label>` for solid edges, `<fromAlias> ..> <toAlias> : <label>` for dashed, and `<fromAlias> -[hidden]-> <toAlias> : <label>` for hidden edges. If label is empty, emit `<fromAlias> --> <toAlias>` (no colon). Alias = the sanitized node id used in the declaration. Escape labels containing double-quotes (backslash-escape) and strip braces from labels to avoid breaking the syntax.

  5. Determinism + stability: same state → same output (iterate in insertion/id order, no Math.random, no Map iteration-order reliance beyond the spec guarantee — prefer arrays). Output is diffable: package blocks grouped, then unzoned, then edges (per RESEARCH Pattern 4).

  Round-trip scope statement (document in a comment above pumlSerialize): positions and colors do NOT round-trip — PlantUML text has no coordinate concept. AC-3 holds at the model level (nodes, edges, zone containment, labels), not the pixel level.
  </action>
