  1. PUML_STEREOTYPE_MAP — a plain object mapping PlantUML element keywords to editor TYPES keys. Cover the RESEARCH subset: database→"database", node→"server", cloud→"cloud", actor→"person", queue→"server" (no queue type — record raw keyword in meta), artifact→"document", boundary/control/entity→"process", card/collections→"workstation", frame/folder→"org", interface→"connector" (if TYPES has connector; else "server"), component→"workstation" (generic default), usecase→"process", storage→"nas", rectangle/stack→"server". Unknown keyword → TYPES fallback "workstation" (the generic node) with the raw keyword kept in node.meta.pumlKind. The map value is a TYPES key string; the keyword itself is the map key.

  2. normalizeLines(text): split on /\r?\n/, strip `'` line comments and block comments `/'...'/` (truncate a line at the first standalone `'` not inside a quoted label), trim trailing whitespace, drop empty lines. Return string[]. Guard against catastrophic backtracking: use non-capturing alternations, anchored patterns, and avoid nested quantifiers like (a+)+. A simple indexOf-based comment stripper is acceptable and preferred over regex for the `'` case.

  3. parseDeclaration(line, ctx): match element keyword (PUML_STEREOTYPE_MAP keys, longest-first to avoid prefix clashes), then optional `"Display Label"` (double-quoted), then optional `as alias`, then optional `<<stereotype>>`. Return {alias, display, keyword, stereotype, kind:"node"}. Alias defaults to display or keyword+counter. Sanitize alias: replace non-alnum runs with "_" (prototype-pollution guard — never use an alias as an object property key without sanitization; store parsed nodes in an array, keyed by sanitized alias in a Map). Record display label as node.label.

  4. parseArrow(line, symbols): detect connectors containing -->, ->, ..>, .>, -[hidden]->, and directional -left->/-right->/-up->/-down-> variants (long `-->-->` collapses to one arrow). Left/right sides may be bare aliases, bracketed `[alias]`, or quoted labels. Capture optional `: label` suffix. Return {fromAlias, toAlias, label, style:"solid"|"dashed"|"hidden"}. Use bounded regexes (no nested quantifiers). Hidden edges carry style:"hidden".

  5. pumlParse(text): drive normalizeLines, then iterate with a brace-depth stack (array of zone labels). Per line: strip comment, trim; if line matches `package NAME {` (or `package "Display" as alias {`) → push a zone frame {label, alias, nodes:[], children:[]} onto the stack; if line is `}` or `end package` → pop the stack and attach the popped zone to the parent (or to top-level zones if stack empty); if line is an arrow (parseArrow) → push to edges; else if parseDeclaration matches → create a node, attach to the current top-of-stack zone's node list (containment), push to nodes; else → push the raw line to warnings (skinparam/title/caption/note/!include/hide/remove). Enforce a brace-depth cap of 64 (MAX_PUML_DEPTH) — if depth exceeds it, stop nesting and record a warning ("brace depth cap exceeded at line N — remaining nesting flattened"). Return {zones (flat list with containment refs), nodes, edges, warnings}. The parser is synchronous and uses only local variables — no shared mutable state, so concurrent/overlapping calls are safe (edge-probe M-20/concurrency).
  </action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pasted/uploaded .puml text → parser | untrusted user-supplied (or third-party) text crosses into pumlParse; its output becomes DOM via renderAll |
| parsed aliases → state object keys | sanitized aliases are used as Map keys / node ids, never as raw object property names |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | DoS (ReDoS) | pumlParse regexes (normalizeLines/parseArrow/parseDeclaration) | high | mitigate | Use non-backtracking patterns: anchored, no nested quantifiers like (a+)+; prefer indexOf/string ops for comment stripping over regex; parseArrow uses a single bounded alternation per connector type. Acceptance: a 50KB malformed .puml parses in <500ms; no catastrophic backtracking. |
| T-04-02 | Tampering / prototype-pollution | parseDeclaration alias → state keys | high | mitigate | Sanitize every alias before use: replace non-alnum with "_", never use an unprefixed alias as an object property key (store parsed nodes in an array + Map keyed by sanitized alias). Acceptance: an alias "__proto__" or "constructor" is sanitized and cannot shadow Object.prototype. |
| T-04-03 | DoS (infinite loop) | pumlParse brace-depth tracker | medium | mitigate | MAX_PUML_DEPTH=64 cap; exceeding it flattens remaining nesting and records a warning instead of recursing. Acceptance: 1000 nested `package N {` lines returns a warnings entry and a model, no hang. |
| T-04-04 | XSS | imported labels rendered into SVG text via renderAll | medium | mitigate | Labels flow through Phase 1's esc()/textContent discipline (inherited — renderAll already escapes). Verify by importing a label containing "<script>" and confirming it renders as inert text. |
| T-04-05 | Repudiation | none (local-only tool, no backend) | low | accept | Client-only single-user editor; no audit trail at ASVS L1. |
