## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| JSON file → state (load) | Untrusted serialized diagram JSON crosses here, including state.journey — prototype-pollution and shape-migration surface |
| keyboard → present/pick handlers | Global keydown handler routes present/pick branches before tool shortcuts — handler leakage surface |
| DOM crash/reload → body.presenting | A crash or reload mid-present can leave body.presenting on the persisted class — cleanup surface |
| narration text → DOM | Author-typed step.note rendered in caption/modal — XSS surface if ever set via innerHTML |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-03-02 | Information disclosure / XSS | narration caption + journey modal | high | mitigate | All narration text reaches the DOM via textContent or input.value, never innerHTML; no HTML interpretation, trimming, normalization, or length limit (Task 1 + Task 2 actions). |
| T-03-03 | Elevation of privilege | global keydown handler — present/pick branch ordering | medium | mitigate | Present and picking branches are evaluated before tool shortcuts and return early; exitPresent and endPick clear the present/picking flags so no handler leaks after exit (Task 1 + Task 2 actions). |
