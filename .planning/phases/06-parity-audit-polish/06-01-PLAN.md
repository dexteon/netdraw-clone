Assert equal → PASS/FAIL line. For the empty/encoding edge probe: also run the import on an empty .puml string and assert it yields zero nodes/edges (no throw, no garbage).

|----------|-------------|
| file:// → index.html | App loads from local filesystem; no server, no network — zero-dep invariant (TS-1/TS-5) |
| Playwright devDep → shipped app | Test tooling (playwright) is dev-only; must NOT be imported into index.html |
| audit.mjs → index.html functions | Script reads app state via page.evaluate; no data leaves the machine |
| git push → GitHub | Repo contents pushed to a remote; secrets in commits are an exposure |
